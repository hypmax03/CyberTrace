# CyberTrace - Security Policy

## Supported Versions
Only the latest release on the `main` branch is actively supported with security updates.

## Reporting a Vulnerability
If you discover a security vulnerability within CyberTrace, please report it privately:
1. Do not open public issues regarding potential vulnerabilities.
2. Contact the maintainers directly or use GitHub Private Vulnerability Reporting.
3. Provide detailed steps to reproduce the issue.
